# LIFF Questionnaire

This folder is a static LIFF answer page that can be deployed to GitHub Pages.

## Required URL parameters

- `oaId`: SuperPages OA id, for example `1`
- `surveyId`: Survey key generated by SuperPages
- `liffId`: LINE LIFF id

## Optional URL parameters

- `apiBaseUrl`: SuperPages backend API base URL. Default is `https://irl-svr.ee.yzu.edu.tw:5017/api`
- `defaultTags`: comma-separated tags, for example `VIP,課程名單`
- `botAppName`: bot/app name to record with the response
- `appName`: optional app name marker

Example:

```text
https://your-github-name.github.io/liff-questionnaire/?oaId=1&surveyId=abc123&liffId=1234567890-AbCdEf&defaultTags=VIP,課程名單&botAppName=yzulabuse
```

Set this GitHub Pages URL as the LIFF Endpoint URL in LINE Developers.
